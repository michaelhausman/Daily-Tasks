# Feedback

What people actually said, kept verbatim, with a triage against what exists.

One file per person per round, named `YYYY-MM-DD-name.md`. Raw feedback is
preserved unedited — paraphrasing loses the thing that made it worth reading.
Commentary is clearly marked as commentary.

## Status labels used in triage

| Label | Means |
|---|---|
| **Built** | Working in the deployed app today |
| **Partial** | Some of it exists; the useful part doesn't |
| **Open** | Not started |
| **Fork** | Not a feature — a decision about what the product is |

## How to use this

Before starting a change, check whether someone already flagged it. Feedback
that keeps recurring across people matters more than any single person's
enthusiasm, including the builder's.
