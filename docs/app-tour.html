Run it

Four commands on your own machine

You’ll need Node.js 20 or newer — run node -v to check. Nothing else: no database to install, no accounts, no API keys. 

# get the code
git clone https://github.com/michaelhausman/Daily-Tasks.git
cd Daily-Tasks
git checkout claude/media-sharing-tagging-platform-inmmg3

# set it up and start
npm install
npm run db:migrate
npm run seed
npm run dev
  1. npm installPulls the dependencies. Takes the longest — about a minute.
  2. npm run db:migrateCreates the local database file. Instant.
  3. npm run seedFills it with the Aimee Mann example below, so the app isn’t empty on arrival.
  4. npm run devStarts it, then open localhost:3000.
Log in as michael with password password123 to upload. Any of the four seeded accounts work — dana_k, rivera, toneflora — same password. To wipe it and start clean: rm -rf .data, then migrate and seed again.
What you’ll see

The home page

Moments first, then everything recent. A moment is a performer, a place, and a day — pooled from everyone who was there.

The idea, working

Your exact example

Five different people uploaded from the Aimee Mann show at the Eau Claire festival on July 24 — photos, a video, and a board recording. None of them created an event or joined a group. They each tagged three things, and the page assembled itself.

When

Browsing

Pick one tag or all of them

Picking two names in the same row widens the search — either performer. Picking across rows narrows it. So “Aimee Mann” alone gives you everything of hers ever; adding the festival and the date lands you on that one show.

Uploading

Why the tags actually hold together

Typing AIMEE M offers the existing Aimee Mann with its upload count, rather than quietly creating a fifth spelling. This is the part that decides whether the whole idea works: two people typing the same name differently is how a pool splits in half without anyone noticing.

Once it’s running

Worth clicking, in this order

  • /Start here. Four moment cards, then recent uploads.
  • /m/aimee-mann/…Your example. Five people, three media types, one page.
  • /exploreClick “Aimee Mann” alone, then add the festival, then the date. Watch the count drop from 6 to 5 to 4.
  • /uploadLog in first. Drop in a photo from your own phone — if the camera recorded a date, the field fills itself.
The real test: upload something of your own tagged Aimee Mann / Eau Claire Festival / July 24 2026, typed however you like — lowercase, extra spaces, doesn’t matter. It should land in that moment alongside the other five and bump the count to six.
The next step

Putting it on the internet

Right now it stores everything in a file on your machine, which is what makes it run with no setup. To put it somewhere other people can reach, two things need to change: the database moves to Postgres, and uploaded files move to object storage like S3 or Cloudflare R2.

Both already sit behind adapters, so that’s a swap rather than a rewrite — but it does mean signing up for a host and handing over keys. Worth doing once you’ve clicked around and know what you want changed. I’d also want moderation tooling in place before it’s genuinely public.
